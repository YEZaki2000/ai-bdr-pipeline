# Setup

## Vereisten
- n8n self-hosted via Docker
- .NET 8 SDK
- OpenAI API-sleutel
- Hunter.io API-sleutel (gratis)
- Google-account
- Slack-werkruimte

## Stappen
1. Kloon deze repo
2. Deploy F# service op Railway
3. Importeer n8n-flows/bdr-main-flow.json in n8n
4. Stel credentials in (zie README)
5. Maak Google Sheet aan met tabblad "Leads"
6. Zet workflow op Actief
